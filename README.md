# Cute Live Kit

Bộ overlay TikTok LIVE: màn chờ, tạm vắng, kết thúc, ảnh bìa, overlay in-game và alert. Mở `index.html` để chọn game, linh vật, chỉnh chữ và copy link từng màn.

## Đưa lên GitHub Pages (link cố định, chạy mãi)

1. Đăng nhập github.com, bấm **New repository**, đặt tên `cutelive`, chọn **Public**, bấm **Create repository**.
2. Ở trang repo vừa tạo, bấm **uploading an existing file**. Kéo **toàn bộ nội dung** folder này (index.html, các file .html, folder `assets`) vào, bấm **Commit changes**.
3. Vào **Settings → Pages**. Ở **Branch** chọn `main`, folder `/ (root)`, bấm **Save**.
4. Chờ 1–2 phút, link sẽ là `https://<tên-github>.github.io/cutelive/`. Mở link đó, chỉnh xong thì bấm **Copy link** ở từng màn để dán vào OBS.

Muốn sửa sau này: sửa file trên máy rồi upload đè lên repo, link giữ nguyên.
